## Rules
- Data lives in src/lib/store.ts as Mongo-style collections in localStorage (frontend-only by user request); swap mutate/useDB for API calls when a backend is added.
- public/main.txt is generated by scripts/main-txt.mjs via a vite plugin on every file change; never edit it by hand.
